# Efectos-de-isla-de-Calor-con-Machine-Learning
Proyecto de IA que predice zonas urbanas con alto riesgo por efecto isla de calor mediante modelos ML como GRU y CNN. Se integró un chatbot en Dialogflow para informar a la ciudadanía, y una canción generada con IA para sensibilizar sobre el cambio climático y promover acciones sostenibles.
